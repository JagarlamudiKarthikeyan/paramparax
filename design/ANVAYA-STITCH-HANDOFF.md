# ANVAYA — Stitch design handoff

**Design project:** [Open the ANVAYA Stitch project](https://stitch.google.com/projects/10412858933242121082?pli=1)  
**Brand:** ANVAYA — India’s Living Heritage Atlas  
**Tagline:** Every tradition has a story  
**Supporting phrase:** Discover. Connect. Preserve.

This handoff records the current design direction and points collaborators to the editable Stitch canvas. The Stitch project is the source of truth for the visual screens. This document adds a design reference to the repository; it does not replace or alter the existing application.

## Design system

- Warm ivory: `#F4EFE5`
- Charcoal: `#262C35`
- Terracotta: `#963F2D`
- Antique brass: `#B18A4A`
- Forest green: `#485D4A`
- White: `#FFFFFF`
- Editorial serif headings in the Cormorant Garamond style; clean DM Sans-style interface text.
- Premium editorial layouts, cultural photography, clear provenance and generous whitespace.
- Desktop artboards: 1440px. Mobile artboards: 390px.
- Page content uses a subtle 400ms right-to-left slide-and-fade reveal. Shared navigation stays stationary and reduced-motion preferences are respected.

## Shared navigation

**Desktop:** Home · Explore India · Living Traditions menu (six discipline pages) · Workshops · Community Gallery · About, with search, exhibition mode, and Contribute controls.

**Mobile:** Home · Explore · Traditions · Gallery · More. Traditions provides the six discipline pages; More provides Workshops, Artisans & Communities, and About.

## Team workflow

- Review and edit the visual screens in the linked Stitch project.
- Use this repository for implementation work, review notes, and team coordination.
- Keep the Stitch frames and this handoff aligned when the design changes.
- The existing application is being rebranded as ANVAYA. The Stitch work remains the visual design source of truth; this handoff preserves the existing backend behavior.
